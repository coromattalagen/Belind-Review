# BELIND — WebOus Preview (v1.1)

تشغيل: `npm install` ثم `npm run dev` — للنشر: `npm run build` (المخرجات في dist/).

## الأمان
- CSP + رؤوس الحماية في `index.html` و`public/_headers` (Netlify / Cloudflare Pages). على Vercel/Nginx انقلها إلى إعداد الرؤوس.
- `frame-ancestors` و HSTS لا تعمل إلا كرؤوس HTTP، فلا بد من تفعيل `_headers` على الاستضافة.
- السلة تُعاد بناؤها من بيانات الكتالوج (لا يمكن التلاعب بالأسعار عبر التخزين المحلي).
- تنظيف مدخلات النموذج، حقل فخ للبوتات، رمز طلب عشوائي آمن، أُزيلت الاعتماديات غير المستخدمة (express, genai...).
- شغّل `npm run audit` قبل كل نشر.

## يجب تأكيده مع بلند قبل النشر
الأسعار، حد الشحن المجاني (90$) ورسوم الشحن (8$)، مدد التوصيل، أرقام واتساب، والنوتات العطرية — كلها قيم افتراضية من القالب وليست بيانات مؤكدة.
